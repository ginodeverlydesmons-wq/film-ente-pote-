Regarder un film à deux

Une personne crée la salle et charge la vidéo, l'autre rejoint avec le code. La lecture, la pause et l'avance se synchronisent entre les deux écrans.

Cette salle n'existe pas encore, vérifiez le code.
Envoyez ce code à votre ami·e pour qu'il/elle rejoigne la salle.

Charger la vidéo

Collez un lien direct de vidéo (.mp4, .webm…) ou un lien YouTube.

Avec YouTube, la synchronisation dépend du lecteur YouTube lui-même et peut être un peu moins précise qu'avec un lien vidéo direct.

En attente

Vous avez rejoint la salle. La vidéo apparaîtra automatiquement dès que votre ami·e l'aura chargée.

Synchronisé
Le code de salle relie les deux écrans — envoyez ce même site (le lien GitHub Pages) à votre ami·e.
